# Fresh Start

Agency operating desk for credit repair — intake client credit report PDFs, generate dispute letters, and deliver or mail on their behalf.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Interactive agency demo lives at `/demo`.

## Notes

This repository currently ships a polished marketing site plus an interactive **mock** demo (report analysis and mailing are simulated). Live PDF parsing and mail integrations are planned for a later build.
